Parameters

Returns
true si le chargement est réussi, false sinon

Cette fonction :

  1. Lit tous les noeuds du fichier OSM
  2. Crée les arêtes à partir des <way> de type highway
  3. Définit les coordonnées X/Y des noeuds en mètres
